# Minha Lista de Tarefas

Projeto desenvolvido em React como atividade da disciplina de DevOps.

## Sobre o projeto

A aplicação permite criar uma lista de tarefas de forma simples e organizada.

O usuário pode:

- Adicionar novas tarefas;
- Marcar tarefas como concluídas;
- Excluir tarefas;
- Visualizar todas as tarefas cadastradas.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Git
- GitHub

## Objetivo

O objetivo deste projeto é praticar conceitos básicos de desenvolvimento com React e, ao mesmo tempo, aplicar conceitos de DevOps utilizando Git e GitHub para controle de versão.

Durante o desenvolvimento foram utilizadas branches, commits e Pull Request para organizar a evolução do projeto.
